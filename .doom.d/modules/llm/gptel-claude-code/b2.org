#+TITLE: E2E Test: MCP Tools, Subagent (Tests 4, 7)

* README: How to run these tests
This file tests: MCP tool called BY Claude Code, subagent inline output.

Test 5 (permission prompt) is gone: the =permission_prompt= MCP tool and the
=--permission-prompt-tool= flag were removed, so under =--permission-mode
default= Claude Code has no way to ask and the test could only hang.

Prerequisites:
1. Enable =gptel-mode=: =M-x gptel-mode=
2. Set debug logging: =(setq gptel-log-level 'debug)=
3. Ensure MCP server is running (mcp-server-lib HTTP on port 18684)
   Check with: =(mcp-server-lib-http--running-p)= or similar
4. Each top-level heading is an independent test

* Test 4: MCP tool called BY Claude Code
This tests that Claude Code can discover and call Emacs MCP tools
during a query. The MCP config with session-aware URL should route
the tool call back to this buffer's session.

@user: Use the emacs MCP tools available to you. Call the =list_buffers= tool to list currently open Emacs buffers. Show me the first 10 buffer names from the result.

** Verification
- [ ] Claude Code called the =list_buffers= MCP tool (check tool use blocks in response)
- [ ] Tool call was routed through session-aware MCP endpoint
- [ ] Tool result was returned and Claude Code displayed buffer names
- [ ] =*Messages*= shows =--mcp-config= with session-specific URL
- [ ] No MCP routing errors in =*Messages*= or =*Warnings*=

* Test 7: Subagent inline output
This tests that when Claude Code spawns a subagent (via Agent tool),
the stream_event messages with =parent_tool_use_id= are handled correctly.

Note: Claude Code uses subagents internally for complex tasks. The
=--include-partial-messages= flag should include subagent output in the stream.

@user: Use the Agent tool to search for files matching "*.org" in the current directory. Show the results.

** Verification
- [ ] Claude Code spawned a subagent (Agent tool use block visible)
- [ ] Subagent output appeared in the response (file listing)
- [ ] No errors related to =parent_tool_use_id= in =*Messages*=
- [ ] Tool use and result blocks are properly formatted in org
- [ ] The response completed cleanly after subagent finished
